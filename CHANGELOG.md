# v0.2.0-beta.1
- Rebuilt on a modern Electron runtime with bundled, checksum-pinned yt-dlp and ffmpeg for macOS (Apple silicon) and Windows
- Sign in to YouTube from the desktop app, with credentials encrypted on the device
- Review each match against the VOD with precise In/Out controls, then download the batch with per-clip progress
- Edit each clip's thumbnail players, characters and round, with a live preview
- Generate video titles that fit YouTube's 100 character limit
- Upload to YouTube with a playlist, per-video progress and safe retries
- Keep the open batch when switching between Source, Match review and Output
- Retrieving sets can be cancelled and no longer hangs
- New app icon and a redesigned interface
